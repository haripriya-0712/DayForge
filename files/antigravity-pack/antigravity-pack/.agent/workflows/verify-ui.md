# verify-ui

Visually verify the running app.

1. Start backend and frontend if not running.
2. Open the app in the browser agent.
3. Check every page built so far at 390px and 1280px width, in light and dark themes.
4. Check: spacing consistency, contrast, touch targets, empty/loading/error states, animations.
5. Capture screenshots as artifacts, list every UI issue found, then fix them.
